## 素材ファイルについて（同梱済み）

書籍本文と同じファイル名の画像・音声を、各フォルダにあらかじめ同梱してあります。
zipを展開してそのままブラウザで開けば、画像・音とも動作します。

- image1.png（第1章。紫の丸に星マークのアイコン）
- bg1.png（第5・6章：明るい水色の空＋雲の背景画像。得点表示の黒文字が読めるよう明るめにしています）
- target1.png（オレンジの角丸ターゲット） / player1.png（水色のプレイヤーバー） /
  ball1.png（ピンクのボール）
- audio1.mp3（第5章・6.1章：命中音。ビープ的な短いチャイム）
- hit.mp3（第6章6.2：命中音。audio1.mp3と同じ音） / miss.mp3（見逃し音。低いブザー音） /
  bgm.mp3（BGM。4音のアルペジオ。約1.2秒でループする前提の短尺）

これらはすべて画像編集ソフトやサンプル音源ではなく、Pillow（PNG生成）とffmpeg（音声合成）
でこの場で自動生成したプレースホルダー素材です。書籍のイメージに近い配色・雰囲気には
していますが、実際の制作物として使う場合は、お好みの画像・効果音に差し替えてください。

なお11_chapter6_layers.html（複数Canvas重ね合わせ）は単体ファイルなので、
同じ階層に置いた bg1.png を背景として参照します。

## 修正履歴（動作不具合の修正）

初回配布版で、第5章RAF改造版・第6章デザイン版・第6章効果音版の3ファイル
（08, 09, 10フォルダ）が正しく動作していませんでした。原因と対処は以下のとおりです。

1. **`game1 is not defined` エラー（実際にブラウザで動作確認し発見）**
   `index.html`内で`requestAnimationFrame(game1);`を呼んでいましたが、
   `game1`関数は後から読み込まれる`game.js`側で定義されていたため、
   実行時点でまだ`game1`が存在せずエラーになっていました。
   → `requestAnimationFrame(game1);`の初回呼び出しを、`game1`が定義された
   `game.js`の末尾に移動して解決しました。

2. **得点表示が読めない**
   得点は書籍本文どおり`ctx1.fillStyle = "black"`（黒文字）で描画していますが、
   背景画像`bg1.png`を濃紺（夜空）で生成していたため、黒文字がほぼ見えなく
   なっていました。コード側（本文の記述）は変更せず、`bg1.png`を明るい水色の
   背景に作り直すことで解決しました。

3. **11_chapter6_layers.html が実質「何もできない」状態だった**
   従来版は「背景層と前景層を分ける」という概念だけを示す簡易デモにとどまり、
   プレイヤーがマウスに反応しない・得点表示が無い・ターゲットの動きが
   x方向だけで不自然・ボールが最初から画面外にあり分かりにくい、といった
   問題がありました。
   → 第5〜6章で組み上げた本来のゲームと同じロジック（プレイヤーのマウス追従、
   クリックでのボール発射、得点表示、ターゲットの往復運動、deltaTimeによる
   速度正規化）を、背景層(bgCanvas)／前景層(fgCanvas)に分割する形で
   ゼロから組み直しました。背景層は最初の一度だけ描画し、前景層だけを
   毎フレーム再描画するという6.3節の狙いはそのまま維持しています。
   ヘッドレスブラウザで実際にマウス移動・クリックを行い、プレイヤーの追従、
   得点表示、当たり判定（的を静止させた状態）まで動作確認済みです。

なお、第5〜6章のゲーム本体は、的（ターゲット）が絶えず左右に動き続けるため、
発射したボールが届く約2秒後には的の位置がずれていることがあります。
これはバグではなく、先読みして狙うゲーム本来の仕様です（当たり判定ロジック
自体はヘッドレスブラウザで的を静止させた状態で動作確認済みです）。

## 検証について

全11ファイルについて、ヘッドレスブラウザ（Chromium／Playwright）で実際に開き、
- JavaScriptの構文エラー・実行時エラーが無いこと
- クリック操作でボールが発射され、静止させた的に対して当たり判定・得点加算が
  正しく機能すること
- 画像（png）・見た目のスクリーンショット

を確認済みです。効果音（mp3）の音量バランスや、実際のブラウザでの体感的な
動作速度については、この環境では確認できていないため、お手元でご確認ください。
